About

I'm an engineer working on infrastructure and data systems: Kubernetes in production, PostgreSQL and ClickHouse for sensor data at scale, and the tooling that keeps it all observable and affordable.

This site is where I write things down. Most posts start as a question I couldn't find a measured answer to, like how Hetzner's storage classes actually behave under database load, or whether a Kafka-less CDC pipeline into ClickHouse is viable. They end as benchmarks with reproducible numbers. I try to state the limitations as clearly as the results.

I do software consulting. If you need help with Kubernetes, ClickHouse or data infrastructure, get in touch.
